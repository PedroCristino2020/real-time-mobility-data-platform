# Real-Time Mobility Data Platform

End-to-end Data Engineering platform for collecting, processing and analyzing real-world mobility data.

## Project Goals

- Build a complete Data Engineering pipeline.
- Ingest real-world mobility and transport data.
- Process data using Python and PySpark.
- Design a Bronze/Silver/Gold data architecture.
- Store data using AWS S3 and Parquet.
- Analyze data using SQL and AWS Athena.
- Implement data quality checks and automated testing.
- Integrate Generative AI for natural-language data analysis.

## Planned Technologies

- Python
- SQL
- PySpark
- AWS S3
- AWS Athena
- PostgreSQL
- Parquet
- Docker
- GitHub Actions
- pytest
- LLM APIs
- RAG
